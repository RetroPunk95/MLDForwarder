# Componentes de terceiros

## tdl

- Projeto: `iyear/tdl`
- Site: https://github.com/iyear/tdl
- Versão incluída: `v0.20.4`
- Arquivo oficial: `tdl_Windows_64bit.zip`
- SHA-256 do arquivo oficial: `3f219779c07a4be628c34491b9910c18a3b0a0ca0b0aa4f283bb83ab33b007c8`
- Licença: GNU Affero General Public License v3.0

O pacote distribuído inclui `engine/tdl.exe` sem modificações. No repositório-fonte, o binário é obtido pelo script `download_tdl.bat`, que valida o checksum oficial antes da instalação. A licença e o README originais estão preservados na mesma pasta.

## cryptg

- Projeto: `cher-nov/cryptg`
- Site: https://github.com/cher-nov/cryptg
- Versão incluída: `0.6.0`
- Licença: CC0 1.0 Universal

O `cryptg` é usado pelo Telethon para acelerar em código nativo a criptografia dos uploads em álbuns e do modo de download e reenvio das rotas.
